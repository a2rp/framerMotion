# Global configuration with MotionConfig Q&A

## 1. What does MotionConfig do?

It provides configuration to descendant Motion components, including a fallback transition and reduced-motion policy.

## 2. Where should MotionConfig go?

Wrap the subtree that should share the configuration. An application-level boundary is common, with smaller local boundaries only for real differences.

## 3. Does MotionConfig affect every animation library?

No. It configures Motion components under its React boundary. Other libraries, CSS animations, and videos need their own reduced-motion behavior.

## 4. What does the transition prop set?

It sets a fallback transition for child Motion animations that do not have a more-specific transition.

## 5. Can a child still have its own transition?

Yes. A local transition is more specific than the inherited fallback.

## 6. Does a local transition merge with the global transition by default?

No. A more-specific local transition replaces the fallback by default. Use `inherit: true` when the local transition should inherit defaults and override only selected values.

## 7. What does reducedMotion="user" do?

It respects the device's reduced-motion preference. Motion disables transform and layout animations while other properties such as opacity may continue.

## 8. What does reducedMotion="always" do?

It always applies Motion's reduced-motion behavior, which is useful for previewing or checking that mode.

## 9. What does reducedMotion="never" do?

It does not apply preference-based reduced-motion behavior. It is the default policy.

## 10. Does reduced motion disable every property animation?

No. Transform and layout animations are disabled by Motion's automatic behavior, but properties such as opacity or background color may continue. Use custom logic when the whole animation needs a different result.

## 11. Should I use useReducedMotion as well?

Use `useReducedMotion` when custom application logic needs to adapt, such as stopping a video, changing a custom canvas effect, or removing a bespoke transform.

## 12. What is the nonce prop for?

It passes a Content Security Policy nonce to style blocks generated by Motion. Use the same nonce value as the page's policy.

## 13. Should every app pass a nonce?

No. Only use it when the app has a CSP nonce requirement.

## 14. What does transformPagePoint change?

It maps pointer coordinates before Motion uses them. It is useful for a deliberate coordinate-space correction, not a routine animation setting.

## 15. Should I add a fixed transformPagePoint scale?

Only when the rendered coordinate mismatch is known. Measure the actual scaling and use an element-aware conversion for special spaces such as an SVG viewBox.

## 16. Can nested MotionConfig boundaries be useful?

Yes, when a subtree genuinely needs a different configuration. Keep them limited so developers can understand which defaults apply.

## 17. Why is the global transition not visible on one component?

The component may be outside the provider or have a more-specific local transition. Inspect both the React tree and the component's transition prop.

## 18. Why does opacity still animate with reduced motion enabled?

Motion's automatic reduced-motion behavior disables transform and layout animations; other properties can continue.

## 19. Can reducedMotion="always" remain in production?

It can, but use it only if always-reduced behavior is the intended product policy. It is often used temporarily for inspection.

## 20. How should I test the user preference?

Use `reducedMotion="user"` and enable the operating-system reduced-motion setting. Also inspect custom CSS, imperative sequences, video, and non-Motion effects separately.
